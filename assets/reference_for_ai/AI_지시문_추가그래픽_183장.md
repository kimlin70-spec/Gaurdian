## 제작 목적과 원본

첨부한 Forest_Guardian_Game_Assets.zip은 게임 “숲의 수호자”의 확정 그림입니다. 이 ZIP의 assets와 high_resolution_4x를 원본으로 사용해 같은 숲속 동화풍의 그림을 추가해 주세요.

7살 아이가 아이패드로 하는 도트 RPG입니다. 주인공 그레이스가 오염된 동물들을 정화해 친구로 만들고, 마을에서 동물을 돌보며 집을 꾸밉니다. 귀엽고 따뜻한 분위기를 유지하고, 독·불·어두운 성의 표현도 무섭거나 잔인하지 않게 해 주세요.

묶음 1부터 8까지 번호 순서대로 제작·납품합니다. 분량이 많으면 묶음 안에서도 나눌 수 있으나, 완료한 파일과 남은 파일을 정확히 구분해 주세요.

## 공통 제작 규칙

1. 화풍·외곽선·색감·빛 방향은 원본 ZIP을 기준으로 합니다. 신규 동물·아이콘·가구를 기존 그림 옆에 놓아 비교합니다. 배경과 UI는 캐릭터의 가독성을 해치지 않도록 무늬와 대비를 조절합니다.
2. 모든 납품 그림은 PNG입니다. 모든 픽셀의 알파는 0 또는 255로 제한합니다. 반투명 테두리, 흐린 글로우, 반투명 그림자를 넣지 않습니다. 투명 픽셀의 RGB도 0으로 정리합니다.
3. 독립 스프라이트에는 바닥에 붙는 별도 그림자를 넣지 않습니다. 배경에 필요한 자연스러운 명암과 물체 자체의 음영은 사용할 수 있습니다.
4. 게임용 PNG에는 글자·숫자·워터마크를 넣지 않습니다. 이정표에도 글자를 쓰지 않습니다. 별·하트·방패·화살표 같은 그림 기호는 사용할 수 있습니다. preview의 파일명·검사 설명·임시 한글 UI 문구는 허용합니다.
5. 캐릭터와 세워 놓는 가구·장식은 캔버스 아래 가운데를 배치 기준으로 합니다. 바닥에 놓이는 러그·돌길·화단은 납작한 시점을 유지하고 바닥 점유 영역을 JSON에 기록합니다. 아이콘은 그림의 시각적 중심을 캔버스 중앙에 맞춥니다.
6. 표기된 크기는 assets의 실제 픽셀 크기입니다. 다시 2배 확대하지 않습니다. high_resolution_4x에는 가로·세로 각각 정확히 4배 크기의 세밀한 버전을 넣습니다. 640×480 배경 18장만 예외로 1280×960입니다.
7. 고해상도판도 같은 구도·방향·자세를 유지합니다. 단순 최근접 확대만으로 세밀한 버전을 완성했다고 하지 않습니다. 반대로 고해상도 세부 묘사를 추가하면서 캐릭터의 비율이나 소품을 바꾸지 않습니다.
8. 기존 그림을 사용하는 애니메이션은 각 해상도의 해당 원본을 그대로 복사합니다. assets의 첫 프레임은 assets의 원본과, 고해상도 첫 프레임은 고해상도 원본과 디코딩된 RGBA 픽셀이 완전히 같아야 합니다.
9. 애니메이션은 한 프레임 크기가 일정한 가로 한 줄이며, 여백·구분선·프레임 사이 간격은 0입니다. 움직이지 않는 부분은 그대로 보존하고 프레임마다 새로 생성하지 않습니다. 캐릭터 애니메이션은 원본 팔레트를 늘리지 않습니다. 신규 효과는 효과별로 정한 팔레트를 모든 프레임에서 공유합니다.
10. 기존 무기·가구·아이템과 대응하는 새 그림은 원본 디자인을 활용합니다. 예를 들어 eq_ 무기는 w_ 무기의 칼날·손잡이·보석 모양을 유지하고, deco_bench는 기존 f_bench와 어울리게 합니다. 정확한 복사로 충분한 항목은 복사라고 README에 적어도 됩니다.
11. 바닥·벽의 타일과 모든 640×480 배경은 완전 불투명입니다. 울타리·가구·창문·문·캐릭터·효과·아이콘은 필요한 영역만 불투명하고 나머지는 투명합니다. UI 패널·버튼의 글자 면은 불투명, 모서리 바깥은 투명으로 합니다.

JSON에는 UI마다 slice_insets, content_padding, 글자 권장 색, 눌림 시 글자 이동량을 적습니다. 실제 한글 문구를 넣은 200×60, 300×120 예시를 만들어 장식이 글자를 침범하지 않는지 확인합니다. 원본 PNG에는 글자를 저장하지 않습니다.

## 묶음 3. 아이템·장비·스킬 아이콘 — 35장

각 32×32, 투명 배경. 같은 종류의 아이콘은 외곽선·각도·광원·시각적 크기를 통일합니다. 보통 가장자리 2픽셀 정도를 비워 테두리에 잘리지 않게 합니다.
