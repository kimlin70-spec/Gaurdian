# 숲의 수호자 — 아이패드용 도트 턴제 RPG

Grace 와 함께 만드는 게임. 빌드 도구 없이 `index.html` 하나로 돌아갑니다.
(Phaser 3.87.0, 논리 해상도 320×240을 4배 밀도(1280×960 캔버스)로 렌더링, 100% 터치 조작, 한글 도트 폰트 Galmuri)

## 바로 해보기

### 1) PC 에서 로컬 서버 띄우기 (파일을 더블클릭하면 안 돼요 — ES module 때문에 서버가 필요)

```bash
cd Gaurdian
python3 -m http.server 8000
```

또는 Node 가 있으면:

```bash
npx serve . -l 8000
```

PC 브라우저에서 `http://localhost:8000` 을 열면 됩니다.

### 2) 아이패드에서 접속

1. PC 와 아이패드를 같은 Wi-Fi 에 연결
2. PC 의 IP 확인 (Mac: `ipconfig getifaddr en0`, Windows: `ipconfig` 의 IPv4 주소)
3. 아이패드 Safari 에서 `http://<PC IP>:8000` 열기
4. 가로로 돌리고, 공유 버튼 → **홈 화면에 추가** 를 하면 전체 화면으로 즐길 수 있어요.

### 3) GitHub Pages 로 배포

1. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 변경 (한 번만)
2. `main` 브랜치에 푸시하면 `.github/workflows/pages.yml` 이 자동으로 배포
3. 주소: `https://<깃허브아이디>.github.io/Gaurdian/`

## 조작법 (전부 터치)

| 어디서 | 어떻게 |
|---|---|
| 마을 | 숲처럼 걸어 다니는 큰 지도(화면이 그레이스를 따라감). 땅을 탭하면 그곳으로 걷고, 건물을 탭하면 문 앞까지 가서 들어감. 광장의 반디를 탭하면 힌트. 연못 공원, 쉼터 풀밭(쉬는 친구들이 놀고 있음), 동쪽 놀이터, 보물 상자 3개. 광장 북쪽의 큰 건물이 **왕궁**, 서쪽 길 끝은 **꽃 언덕**. 주민(파랑새·촛불이·돌이·반짝이·거북 할아버지)과 이야기할 수 있음. 지도와 주민은 `src/scenes/VillageScene.js` 의 AREAS, 대사는 `data/dialogues.json` 의 villagers |
| 왕궁 | 앞마당 → 임금님의 방 → 공주 방 / 일하는 방 → (계단) 지하 던전 → 지하감옥. 바닥을 탭하면 걷고, 노란 글자(문)를 탭하면 다른 방으로. 임금님은 숲을 하나 깨끗하게 할 때마다 선물(★60, ◆1). 지하 던전의 오염된 무리 3팀은 부딪히면 전투, 숲에 다녀오면(하루가 지나면) 다시 나타남. 방·사람·문은 `src/scenes/PalaceScene.js` 의 ROOMS, 대사는 dialogues.json 의 palace |
| 숲(탐험) | 가고 싶은 칸을 탭 → 길을 찾아 이동. 상자/NPC/곰을 탭하면 다가가서 상호작용. 적에게 닿으면 전투 |
| 전투 | 공격 / 스킬 / 아이템 / 방어 / **정화**. 적 HP 가 팔찌 기준(처음 25%) 아래로 내려가면 정화 버튼이 분홍색으로 빛남 |
| 동물 | 공격 + 스킬 2개 + 방어 + **자동**. 상태창의 동물 이름을 탭해도 자동을 켜고 끌 수 있음 (이름 옆 `A`) |

- 정화한 **동물** → 구조되어 친구가 됨 (반짝 가방에 들어감, 3마리까지 함께 모험)
- 정화한 **식물** → 맑아져서 사라짐
- 정화한 **보스** → 숲이 회복되고 스테이지 클리어
- 지면 게임오버 없이 여관에서 깨어남 (페널티 없음)
- 자동 저장: 마을 도착, 맵 이동, 전투 후, 여관 (1슬롯, localStorage)

## 돌보기 · 치료 · 집 꾸미기 (Grace 의 아이디어)

- **다친 동물 치료**: 숲에 "아야" 하고 앉아 있는 동물을 탭 → 반짝이는 상처 3곳을 탭해 붕대를 감으면 친구가 돼요. 사슴·여우는 치료로만 만날 수 있어요.
- **친구 레벨(하트 0~5)**: 쉼터에서 동물을 탭 → 놀아주기(숲에 다녀올 때마다 1번), 간식 주기(상점 당근 과자). 하트 4개 이상이면 전투에서 힘이 나요(공격 +10%). 전투에서 쓰러지면 조금 내려가요.
  - 하트가 0이 되면 **삐져서 숨어요**(전투에 못 데려감). 놀아주거나 간식을 주면 돌아와요. 영영 떠나지는 않아요.
- **샤워 미니게임**: 전투할 때마다 더러워져요. 5번이면 "더러움", 8번이면 **감기**(전투 불가, 상점 감기약으로 치료). 샤워는 ① 더러운 곳을 문질러 거품 내기 → ② 줄어드는 원이 딱 맞을 때 탭해서 헹구기(10번 중 6번 성공). 완벽하면 하트 +5, 실패하면 절반만 깨끗해지고 하트 -5. 빠른 동물일수록 어려워요.
- **놀아주기 미니게임**: 간식 받아먹기(좌우로 끌어 받기, 진흙 피하기 20초) / 숨바꼭질(덤불 섞기 3판). 점수에 따라 하트 +8/+15/+22. 하트 보상은 숲에 다녀올 때마다 1번, 보상 없는 '그냥 놀기'는 몇 번이든.
- **보스 문 잠금**: 보스방 문은 그 숲의 오염된 무리를 `bossGate`(지금 8)번 정화해야 열려요. 화면 오른쪽 아래 '정화 n/8'. 마을에 다녀와도 유지돼요.
- **우리 집 + 마당**: 마을의 집에 들어가 가구를 놓아 꾸며요. '마당으로' 버튼으로 마당에 나가면 꽃밭·벤치·새집·돌길·작은 나무·연못·그네를 놓을 수 있고, 함께 다니는 동물들이 놀고 있어요. 가구 가게(별가루)와 제작대(나뭇가지·꽃잎·반짝 돌 재료, 적 드롭/상자)에서 가구를 구해요. 가구 데이터는 `data/furniture.json`.

## 숨은 친구 밀꾸 (우리 집 강아지)

- 집 안에 **포근한 침대**를 놓고 숲에 한 번 다녀오면, 침대 밑으로 하얀 꼬리가 살랑거립니다. 침대(또는 꼬리)를 탭해서 들면 밀꾸가 "멍!" 하고 튀어나와 친구가 됩니다.
- 못 찾고 있으면 마을의 반디가 힌트를 줍니다. 침대를 아직 안 샀으면 침대를 권합니다.
- 밀꾸는 전투 한 번에 두 배로 더러워지고, 더러워지면 회갈색 **밀꾸**, 샤워에 성공하면 새하얀 **밀크**가 됩니다 (그림과 이름이 바뀜). 샤워에 실패하면 밀꾸 그대로예요. 깨끗할 때는 전투에서 조금 더 셉니다.
- 감기에 걸리지 않고, 놀아주기 하트가 1.5배 오릅니다. 스킬은 꼬리 흔들기(공격)와 멍멍 응원(모두 회복).
- 함께 다니지 않을 때는 집 침대 밑에서 낮잠을 잡니다. 함께 다니면 마을에서 그레이스를 졸졸 따라옵니다.

## 옆모습과 전투 연출

- 토끼, 버섯, 그레이스는 옆모습 그림(시범)이 있어서 걸을 때와 전투에서 옆을 봅니다. 전투에서는 아군과 적이 서로 마주 봅니다.
- 공격은 준비 → 달려가기 → 타격 → 맞은 쪽이 밀려남 → 뒤로 폴짝 순서로 1초 안팎입니다. 타격 순간 잠깐 멈추고 화면이 흔들리며, 숫자가 크게 튀어나옵니다.
- 아군 공격은 가끔(12%) **아주 세게!** 들어가 1.5배 피해를 줍니다. 적에게는 없습니다.
- 방어를 고르면 다음 차례까지 방어 자세와 옅은 파란 방패 빛을 유지하고, 쓰러지면 주저앉은 자세가 됩니다.
- 옆모습 그림이 없는 동물은 정면 그림을 좌우로 뒤집어 가는 쪽을 봅니다. 밀꾸·사슴·다람쥐처럼 원래 왼쪽을 보고 그려진 그림도 머리가 앞으로 가게 맞춰 둡니다.
- **양갈래** 머리는 옆모습 머리 그림이 아직 똥머리처럼 보여서, 새 그림을 받을 때까지 정면 그림만 씁니다 (단발·긴 머리는 옆모습).
- 옆모습을 끄려면 `src/config.js` 의 `SIDE_VIEWS` 를 `false` 로 바꾸면 모두 정면만 봅니다.

## 폴더 구조

```
index.html            진입점 (iPad Safari 메타 태그, 세로모드 안내)
src/
  main.js             Phaser 설정, 폰트 로딩, 씬 등록
  config.js           해상도·색·타일 범례 등 상수
  scenes/             Boot → Title → CharacterCreate → StoryIntro → Village ⇄ Field ⇄ Battle → Purify, Village ⇄ Home, Village ⇄ MiniGame
  systems/
    Data.js           JSON 데이터 접근 + {hero} 같은 이름 치환
    GameState.js      진행 상태, 능력치 계산, 경험치/레벨, 구조/파티
    Save.js           localStorage 저장/불러오기
    Assets.js         임시 도트 그래픽 생성 (나중에 PNG 로 교체)
    UI.js             터치 버튼, 패널, 대화 상자, 확인창, 게이지
    Audio.js          웹오디오 효과음/배경음 (첫 탭에서 언락)
data/                 게임 내용 전부 (코드 수정 없이 추가/수정 가능)
assets/               진짜 도트 PNG 를 넣을 곳
vendor/               phaser.min.js (3.87.0 고정), Galmuri 폰트 (OFL)
```

## 데이터만 고쳐서 바꾸기

| 파일 | 내용 |
|---|---|
| `data/strings.json` | 게임 제목, 주인공/안내 동물/세계/마왕/가방 **이름**. 임시 이름을 여기서만 바꾸면 전체 반영 |
| `data/dialogues.json` | 인트로·엔딩·NPC·보스 대사. `{hero}` `{guide}` `{world}` `{king}` `{cage}` `{gem}` 자리표시자 사용 가능 |
| `data/player.json` | 그레이스 능력치, 시작 장비/아이템/별가루 |
| `data/animals.json` | 구조 동물 (이름, 역할, 능력치, 성장, 스킬 2개) |
| `data/enemies.json` | 적 (`kind`: plant / animal / boss, 스킬 가중치, 보상, 드롭) |
| `data/skills.json` | 스킬 (type: damage / damage_all / heal / heal_all, 레벨 1~3 수치) |
| `data/items.json` | 아이템 (heal / mp / revive / heal_all, 상점 판매 여부) |
| `data/equipment.json` | 무기·옷·팔찌 (팔찌의 `purify` = 정화 가능 HP 비율) |
| `data/furniture.json` | 집 가구 (크기, 가격 또는 제작 재료) |
| `data/stages.json` | 스테이지와 맵. `requires` 는 먼저 깨야 하는 스테이지, `theme` 은 타일셋·배경색(눈 숲은 `S W I F X R P c` 글자 사용). `rows` 는 글자 지도 (`.`풀 `T`나무 `=`길 `~`물 `*`꽃 `d`오염 풀 `D`오염 나무 `r`바위 `s`돌바닥 `#`돌벽 `b`덤불), `objects` 는 상자/NPC/출구/보스/다친 동물(injured), `enemies` 는 1~3마리 그룹 |
| `data/assets.json` | PNG 교체 목록. `overrides` 에 적은 키는 코드가 임시 도트를 만들지 않고 파일을 읽음 |

### 새 스테이지 추가 예
`data/stages.json` 의 `stage2` 에서 `"locked": true` 를 지우고 `start`, `boss`, `maps` 를 `stage1` 처럼 채우면 숲 입구 목록에서 바로 갈 수 있습니다.
`"final": true` 인 스테이지를 클리어하면 엔딩 컷신이 나옵니다.

### 진짜 도트 그래픽으로 교체
현재 `assets/` 의 PNG 가 실제 그림입니다 (4배 밀도: 타일 64×64, 주인공 96×128, 동물 64×64). 애니메이션 시트·전투 배경·효과 포함. 자세한 규칙과 새 그림 묶음 적용법은 `assets/README.md`. 느린 기기에서는 `src/config.js` 의 PX 를 2로 낮추고 그림을 절반 크기로 다시 만들면 됩니다. `assets.json` 에 없는 키는 `src/systems/Pixels.js` 의 글자 그림으로 대체됩니다.
`data/assets.json` 예:
```json
"overrides": {
  "tiles":  { "type": "spritesheet", "file": "assets/tiles.png", "frameWidth": 16, "frameHeight": 16 },
  "rabbit": { "type": "image", "file": "assets/rabbit.png" }
}
```
주인공은 `player_body`(피부, 흰색으로 그리면 tint 로 색 입힘), `player_clothes`, `hair_0`~`hair_2`(흰색) 세 겹입니다.
